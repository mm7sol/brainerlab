# 3D explorer

The Explore tab offers a **2D / 3D toggle** over the same circuit data and the
same neuron inspector — no backend change, no new routes.

## How it works

- Three.js `0.169.0` loads **lazily from the jsdelivr CDN** (pinned
  `importmap` in `index.html`) only when the user first clicks **3D**.
  No build step; offline dev falls back to 2D with a message.
- Nodes render as one `InstancedMesh` (type colors), edges as a single
  `LineSegments` cloud; click picking via raycast reuses `selectNeuron()`.
- **Layout honesty**: x/y come from the dataset when present (schematic,
  display-only); z is layered by neuron type with a hash jitter; datasets
  without coordinates fall back to a circular layout. Always illustrative,
  never anatomical.
- Camera auto-frames the graph; `OrbitControls` (damped) for rotate/zoom,
  click-vs-orbit disambiguated by drag distance; selected node gets a
  projected HTML label.
- The render loop pauses when the 3D view is hidden; `prefers-reduced-motion`
  still disables page CSS animation (canvas loops are data views).
- Same 400-node subgraph cap as 2D applies (`setGraph` rebuilds both views).
